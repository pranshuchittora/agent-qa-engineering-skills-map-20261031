# AI Engineering Skills Map · 学习地图

基于 **Andrew Ng** 的 [AI Engineering Skills Map: Building and Deploying AI Applications](https://x.com/AndrewYNg/status/2090840747738374568) 整理的系统学习规划。

## 在线使用

直接打开 [index.html](./index.html) 即可（纯前端，支持本地进度追踪）。

## 功能

- **六大核心技能**系统拆解
- **精选高质量资源**（课程、文章、工具、Cookbook）
- **可选研究补强轨**：从 [AI Crash Course](https://github.com/henrythe9th/AI-Crash-Course) 精炼的论文/视频，不计入主线总进度
- **本地进度追踪**：localStorage
- **轻量前端**：`index.html` + `data.js` + `app.js`

## 使用

```bash
git clone https://github.com/seveniscat/ai-engineering-skills-map.git
open index.html
```
