# AI Engineering Skills Map · 学习地图

基于 **Andrew Ng** 的 [AI Engineering Skills Map: Building and Deploying AI Applications](https://x.com/AndrewYNg/status/2090840747738374568) 整理的系统、全面、深入学习规划。

## 在线预览

直接打开仓库中的 `index.html`（纯前端单页面）。

## 功能特性

- **六大核心技能**系统拆解：
  1. LLM Foundations
  2. Machine Learning Foundations
  3. Grounding models with data
  4. Building agentic systems
  5. Evaluation-driven development
  6. Operating in production

- **精选高质量资源**（课程、文章、工具、Cookbook）直接可点击跳转
- **本地进度追踪**：勾选学习目标，进度自动保存到浏览器 `localStorage`
- **响应式轻量设计**：单文件 HTML + Tailwind CDN，无后端依赖

## 如何使用

1. 克隆仓库：`git clone https://github.com/seveniscat/ai-engineering-skills-map.git`
2. 用浏览器打开 `index.html`
3. 按侧边栏导航学习，勾选已完成的目标
4. 进度会自动保存在本地（可随时重置）
