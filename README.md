# AI Engineering Skills Map · 学习地图

基于 **Andrew Ng** 的 [AI Engineering Skills Map: Building and Deploying AI Applications](https://x.com/AndrewYNg/status/2090840747738374568) 整理的系统学习规划。

## 在线预览

直接打开 `index.html`（纯前端，无后端依赖）。

仓库：https://github.com/seveniscat/ai-engineering-skills-map

## 功能

- 六大核心技能系统拆解
- 精选高质量资源（课程、文章、Cookbook、工具）可点击跳转
- 本地进度追踪：勾选目标后自动保存到 `localStorage`
- 侧边栏导航 + 响应式设计

## 文件结构

- `index.html` — 页面结构
- `data.js` — 学习目标与精选资源
- `app.js` — 渲染与进度追踪

## 使用

```bash
git clone https://github.com/seveniscat/ai-engineering-skills-map.git
open index.html
```

进度保存在浏览器本地，可随时点击「重置进度」。
